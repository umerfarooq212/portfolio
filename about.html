about

.NET developer focused on reliable, well-documented APIs.

3+ years of experience building RESTful APIs, webhooks, and microservices with C#, ASP.NET Core (.NET 6/8), and .NET Framework on SQL Server and PostgreSQL.

I build and maintain backend systems for enterprise clients — RESTful APIs, webhooks, and microservices secured with JWT and OAuth 2.0, documented with Swagger/OpenAPI, and deployed through Microsoft Azure and Azure DevOps CI/CD pipelines. I work with third-party integrations, Rebus service-bus messaging, and SignalR for real-time features.

A large part of my focus is API performance and reliability: query optimization, JMeter load testing, and code reviews. I use agentic AI tools like Claude and GitHub Copilot as part of my day-to-day development workflow.

I work well with international clients and cross-functional teams, produce clear technical and API documentation, and have mentored junior developers through code reviews and knowledge sharing.
